STEP BY STEP

From device code to activation.

  1. 01

    Copy your Device Code

    Open the activation screen in PDT on the computer you want to use. Copy the Device Code exactly as it appears.

    IN THE PDT APP
  2. 02

    Submit your request

    Open the activation portal, choose User login, and sign in with ChatGPT. Complete your name and company details if this is your first visit. Paste the code and select Request activation.

    IN THE PORTAL
  3. 03

    Apply your approved key

    Check your request in the portal. Once it is approved, copy the activation key and paste it into PDT’s activation screen on the same computer.

    BACK IN THE PDT APP

HELP WITH ACTIVATION

A few useful answers.

My request says “Pending.” What happens next?

Your administrator needs to review the request. Check the portal again for its status. The key becomes available after approval; submitting a request does not automatically activate PDT.

Can I use the same key on another computer?

Each activation key is tied to the submitted Device Code. To activate another computer, submit that computer’s code for review.

Why does the address change when I open the portal?

This website contains the activation guide. Account sign-in, request status, and activation keys are handled in the separate PDT portal, so your browser shows its address when you continue.

What if my request is rejected?

Open the request in the portal and read the administrator’s note. Resolve the issue described there, then submit a new request if needed.
